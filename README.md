# Sistema de Gestão de Prazos de Entrega

## Estrutura do Projeto

- `frontend/` — Aplicação React + TypeScript
- `backend/` — API Node.js + Express + TypeScript

## Funcionalidades
- Upload de planilha CSV
- Entrada manual de programação logística
- Cálculo de prazos conforme regras do SCRIPT.txt
- Geração de tabela e HTML conforme template

## Como rodar
Veja instruções nas pastas `frontend` e `backend` para rodar cada parte do sistema.
